# Bampton Charter Fair — Public Stallholder Directory (Prototype)

A test GitHub Pages site with searchable historic 2026 public listings. **NOT confirmed 2027 traders.**

Upload `index.html` and `stalls.json` to the root of the repository. Enable Settings > Pages > Deploy from branch > main > /(root).

In Wix use an Embed HTML iframe URL to the published GitHub Pages site. Set the frame height to approximately 1000px initially and test mobile separately.

Data: Bampton-Fair-2026-Public-Print-Views.xlsx, `STALL NO PUBLIC` sheet. Do not add contact details. Map integration is not included in this first prototype.
